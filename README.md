# Poker C++ / SFML

Jeu de poker Texas Hold'em en développement avec **C++** et **SFML**.

## 🚧 Statut

**Projet en cours** - Version alpha, nombreuses fonctionnalités à venir !

## 🎯 Objectif

Créer un jeu de poker jouable avec interface graphique, incluant :
- Logique complète du Texas Hold'em
- Modes solo (contre IA) et multijoueur local
- Interface intuitive avec SFML

## ✅ Avancement actuel

- Structure de base du jeu (classes Cartes, ...)
- Affichage graphique des cartes


## 🔧 Technologies

- C++17
- SFML 2.6
- CMake

## 🚀 Compilation rapide

```bash
git clone https://github.com/BouBoule69/poker-sfml.git
cd poker-sfml
mkdir build && cd build
cmake ..
make
./poker
